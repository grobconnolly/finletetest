# Extractable components
> Generated by Superdesign init. Repository: Finlete (finlete.com). Fans buy Regulation CF shares that pay a % of an MLB prospect's future MLB earnings.
> Stack: the production homepage is **static HTML + vanilla CSS** in `redesign/` (no framework, no component library, one stylesheet with CSS custom properties). It is copied to `nextjs/public/redesign/` and served at `/redesign` by a Next.js 16 (App Router, React 19, Tailwind v4) app in `nextjs/`, which also has an older React prototype at `/app`. Root-level `*.html` files are a saved snapshot of the current live site (Framer export), kept for reference only.
> Design rules live in `DESIGN.md` (tokens, page order, wording the page must never use).
